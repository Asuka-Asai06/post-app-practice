### ユースケース記述
#### UC-05: 投稿を編集する

- **アクター**: ログインユーザー
- **事前条件**: ログインユーザーが編集対象の投稿の投稿者であること
- **基本フロー**:
  1. ログインユーザーが投稿一覧画面で「編集」ボタンを押す。
  2. システムが投稿編集画面に、現在のタイトル・カテゴリ・本文を入れて表示する。
  3. ログインユーザーが「更新」ボタンを押す。
  4. システムが投稿を書き換えし、投稿一覧画面へリダイレクトする。

- **代替フロー**:
  - 1a. 他人の編集画面に直接アクセスした場合：システムは編集画面を表示せず、権限が無いことを伝える。
  - 3a. タイトルまたは本文が空の場合 : システムはエラーメッセージを表示し、投稿を書き換えない
- **事後条件**: 対象の投稿の内容が書き換わり、投稿一覧画面に反映される
- **受け入れ条件**:
  - [ ] 投稿一覧画面で、自分の投稿にだけ「編集」が表示される
  - [ ] 内容を書き換えて「更新」を押すと、投稿一覧画面に書き換えた内容が表示される
  - [ ] タイトルを空にして「更新」を押すと、エラーメッセージが表示され、投稿の内容は変わらない
